# Aetheria Android — Godot 4

Android test build v0.3.0.

- APK: [Download Android APK](https://github.com/xdforeverxd/123/raw/refs/heads/android-download-v0.3.0/aetheria-godot-android-debug.apk)
- Godot project: [Download source ZIP](https://github.com/xdforeverxd/123/raw/refs/heads/android-download-v0.3.0/aetheria-godot-project.zip)

Requires Android 7.0+, OpenGL ES 3, arm64-v8a or x86_64. Single-player offline prototype. Not a Google Play release. Physical Android device testing is pending.

Install the APK to play. To edit, extract the ZIP and import Aetheria/project.godot using Godot 4.6.3. Previous WebView saves are not automatically migrated.

If GitHub asks you to sign in, use an account with access to this repository.
